## 关于

这个网站用于展示我设计的作品，重点记录「从想法到可实现」这一段：把模糊的产品意图，翻译成有分层、有边界、有数据契约的系统架构。

每件作品都按同一套结构整理 —— 背景与目标、设计思路、架构总览、分层解读、能力清单、核心机制、应用场景、亮点与难点、后续规划 —— 方便横向对比设计思路。

## 收录作品

### 图谱智学 · 学习辅助智能体

以图谱为纲 · 以闭环为法

一套以「知识图谱」为知识组织主轴、以「学习闭环」为运行法则的个性化学习辅助智能体。把教材等原始素材自动转化为结构化知识图谱，再通过「建图谱 → 学知识 → 练测 → 诊断反馈 → 计划调整 → 复盘报告」的六步闭环，为每位学习者提供动态、可信、可追踪的个性化学习体验。

设计成果包括：

- **四层架构**：数据层 / 引擎层 / 应用层 / 表现层，附完整数据契约与闭环回路
- **17 个原子能力**（S1–S17）：每个能力独立可评测、可替换，均有输入参数、输出格式与错误码
- **三大核心机制**：图谱构建（含置信度过滤与环路检测）、掌握度闭环（指数移动平均）、资源可信（两道强制校验门）
- **5 个应用场景**：日常复习 / 考前冲刺 / 错题攻克 / 多语言学习 / 终身学习
- **12 条非功能需求**：性能、可靠性、可用性、扩展性、安全与隐私、鲁棒性均有可验收标准

## 技术说明

本站为**纯静态站点，零构建**：不使用任何框架、不需要编译步骤，克隆后直接打开 `index.html` 即可运行。

```
index.html          首页（单页滚动：Hero / 精选作品 / 全部作品 / 关于我 / 联系方式）
works.html          全部作品列表页
work.html           作品详情页（通过 ?id= 参数读取数据渲染）
data/works.js       作品数据 —— 唯一需要维护的内容文件
styles.css          样式（深色科技感主题、响应式、灯箱）
script.js           交互（数据渲染、图片灯箱、滚动动效、一键复制）
assets/works/       作品图片资源
```

### 设计上的一个关键取舍

结构化案例页通常依赖构建工具生成，但本站要求零构建。为避免「每增加一件作品就复制一份详情 HTML」，本站采用**数据与视图分离**：

- 全部作品信息集中在 `data/works.js`
- 列表页与详情页均由该文件渲染
- **扩展作品 = 追加一条数据 + 放入图片，无需改动任何 HTML**

留空的字段会被自动跳过，不会在页面上留空白。
